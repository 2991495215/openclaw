### Highlights

- **Safer updates and recovery:** package updates now refuse unsafe swaps when service inspection is unavailable, and `gateway stop` can recover a frozen startup owner instead of leaving future starts blocked. (#171101, #171678) Thanks @RomneyDa, @homeworld520, @Yolo521-bot, and @TommyLei666.
- **Windows startup reliability:** fresh Windows state stores, Proxy-backed environments, and SQLite update helpers no longer block Gateway startup or flash helper windows. (#176174, #176194, #174969) Thanks @RomneyDa, @tjarrau-dev, @skyzhao1223, @easyteacher, and @throwingbones.
- **Upgrade recovery:** held system agents recover after schema-changing updates and live config survives failed recovery snapshots. (#175007, #176783, #171217) Thanks @RomneyDa, @PennyVibe, and @Yolo521-bot.
- **Doctor repairs retired plugin metadata:** Doctor removes empty retired-plugin install records so legacy metadata cannot keep the Gateway configuration invalid. (#173851) Thanks @RomneyDa and @fengfan201314-eng.
- **Managed plugins stay aligned:** app upgrades converge bundled managed plugins onto the installed core version instead of leaving stale peer links. (#174257) Thanks @RomneyDa and @kazuyuki-eguchi.

### Changes

- This patch release contains focused reliability fixes only; it does not introduce new user-facing features.

### Fixes

- **Updates:** refuse package swaps when the running service cannot be inspected safely. (#171101) Thanks @RomneyDa, @homeworld520, and @Yolo521-bot.
- **Gateway startup:** let `gateway stop` retire an overdue startup holder so a frozen-but-live process cannot strand later starts. (#171678) Thanks @RomneyDa and @TommyLei666.
- **Config recovery:** preserve the live configuration when a forensic recovery snapshot cannot be acquired. (#171217) Thanks @RomneyDa and @Yolo521-bot.
- **System agents:** restore access to agents held by an affected upgrade and recover held system-agent databases after schema-changing updates. (#175007, #176783) Thanks @RomneyDa and @PennyVibe.
- **Windows state:** canonicalize schema ownership across Windows path aliases and serialize Proxy-backed environments before schema-inspection IPC. (#176174, #176194) Thanks @RomneyDa, @tjarrau-dev, @skyzhao1223, and @easyteacher.
- **Windows updates:** hide SQLite helper process windows during update work. (#174969) Thanks @RomneyDa and @throwingbones.
- **Doctor:** repair empty retired-plugin install metadata instead of preserving an invalid retired key. (#173851) Thanks @RomneyDa and @fengfan201314-eng.
- **App upgrades:** reconcile app-managed plugins with the installed core release so bundled Codex, Discord, and Slack plugins do not remain on an older version. (#174257) Thanks @RomneyDa and @kazuyuki-eguchi.
